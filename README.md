MirrorLyrics turns your phone into a lyrics heads-up display for night driving. Place it on the dashboard and the lyrics reflect on the windshield, mirrored so they read correctly.
Detects the playing song from any player (Spotify, YouTube Music, etc.)
Fetches synced lyrics from LRCLIB automatically
Highlights words in real time as the song plays
Mirror, flip and rotate modes for different phone placements
Tap the screen edges to fine-tune sync
Built with Kotlin. The APK is built automatically with GitHub Actions.
